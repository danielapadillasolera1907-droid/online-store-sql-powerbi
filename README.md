# Tienda Online — SQL Server & Power BI

Proyecto de análisis de datos de principio a fin, utilizando **SQL Server, T-SQL y Power BI** para transformar datos de una tienda online en información útil para el análisis y la toma de decisiones.

## 📌 Descripción del proyecto

Este proyecto demuestra un flujo completo de análisis de datos, desde la creación y consulta de la base de datos hasta la transformación de los datos y su visualización mediante Power BI.

El objetivo es analizar los datos de ventas de una tienda online y crear un dashboard interactivo que permita comprender el rendimiento de las ventas y obtener indicadores relevantes del negocio.

## 🏗️ Arquitectura y flujo de datos

El proyecto sigue el siguiente flujo:

**SQL Server → Transformación y análisis de datos → Power BI → Indicadores de negocio**
